# Maintained operator scripts

- `demo/`: permission-safe synthetic demo-packet generation.
- `api/`: export the versioned UI contracts as JSON Schema.
- `intake/`: read-only source ingestion commands.
- `media/`: shared audio/video preparation utilities.
- `meta/`: maintained read-only export/monitoring and explicit-ID pause tools.
- `campaigns/22yards/`: current campaign-specific proof scripts; these are not
  generic product defaults.

Superseded experiments and stale creators are indexed under
`reference/main/scripts/`.
