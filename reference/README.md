# Reference material

Nothing under this directory is imported by the active ADvantage runtime.
Reference files are kept so earlier experiments and design decisions remain
available without competing with maintained product paths.

- `main/` contains code and inputs retained from the earlier `main`-branch era
  that are no longer selected by active workflows.

When reusing an idea, copy the behavior into the appropriate active adapter or
engine, add tests there, and leave the historical source unchanged for
traceability.
